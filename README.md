# AI Interview Coach

교환학생, 인턴·취업, 대입 영어 면접을 브라우저에서 연습하는 코치입니다. 화면은 한국어이고, 면접 질문과 모범 답안은 영어입니다.

목적, 전공, 난이도를 고르면 질문이 말로 나옵니다. 마이크로 답한 뒤 문법, 어휘, 속도, 구조, 적합성을 리포트에서 확인합니다. 발음 음소 점수는 포함하지 않습니다.

## 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 로컬 서버를 켭니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\server.ps1
```

터미널에 출력된 주소로 엽니다. 서버는 `8785` 포트를 먼저 시도하고, 사용 중이면 `8780`부터 `8790` 사이에서 빈 포트를 고릅니다.

`index.html`을 파일로 직접 열면 화면은 보이지만 AI 코치 요청은 실패합니다. 코치 기능은 이 서버를 통해서만 동작합니다.

음성 인식과 질문 읽기는 Chrome의 Web Speech API를 사용합니다. 마이크 권한을 허용해야 답변을 말로 입력할 수 있습니다.

## API 키

프로젝트 루트에 `.env` 파일을 만듭니다. 이 파일은 Git에 올리지 않습니다.

```
gemini_api_key=발급받은_키
groq_api_key=발급받은_키
```

리포트의 AI 코치 구간은 로컬 서버가 Gemini를 먼저 호출하고, 응답이 없으면 Groq로 넘깁니다. 키는 브라우저 JavaScript에 들어가지 않으며, 서버는 `.env` 파일을 내려주지 않습니다.

키가 없어도 규칙 기반 점수, 모범 답안, 단어 사전 조회는 동작합니다. AI 코치 문장만 표시되지 않습니다.

## 연습 흐름

1. 면접 목적을 고릅니다. 교환학생, 인턴·취업, 대입 면접 중 하나입니다.
2. 전공 또는 직무와 난이도(초급, 중급, 고급)를 고릅니다. 전공은 직접 입력할 수 있습니다.
3. 문항 수(3 또는 5)와 문항당 제한 시간(없음, 45초, 60초, 90초, 120초)을 정합니다.
4. 질문을 듣고 영어로 답합니다. 음성 인식 결과는 제출 전에 고칠 수 있습니다.
5. 답이 짧거나 근거가 부족하면 꼬리 질문이 이어질 수 있습니다.
6. 리포트에서 항목별 점수, 추천 어휘, 모범 답안, AI 코치 의견을 봅니다. 영어 단어를 누르면 뜻과 예문이 열립니다.

## 저장

점수와 연습 기록은 이 브라우저의 `localStorage`에 남고, 진행 중인 면접은 `sessionStorage`에 남습니다. 기록은 최근 30회까지 보관됩니다. 서버 포트가 바뀌면 브라우저가 다른 주소로 보아 이전 기록이 보이지 않을 수 있습니다.

AI 코치 요청만 로컬 서버로 전달됩니다. 서버는 그 내용을 Gemini 또는 Groq에 보내고, 받은 코칭을 기록에 다시 저장합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `css/styles.css` | 스타일, 다크 모드, 반응형 |
| `script.js` | 헤드라인, 테마, 오늘의 팁, 추가 마이크 버튼 |
| `js/questions.js` | 질문과 키워드 |
| `js/engine.js` | 세션 구성과 규칙 기반 채점 |
| `js/app.js` | 화면 전환, 음성 면접, 리포트, 사전, AI 코치 요청 |
| `server.ps1` | 정적 파일 제공과 `/api/coach` 프록시 |
